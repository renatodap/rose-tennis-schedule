# Phase 04-02: Audit and Remove Remaining Dead Code

## Objective
Final sweep to find and remove any remaining dead code, unused exports, or orphaned files.

## Context
Full codebase audit after feature removal

## Tasks

### Task 1: Search for unused hook imports
- **Type:** audit
- **Files:** `lib/hooks/*.ts`
- **Action:**
  1. For each hook, grep the codebase to ensure it's actually used
  2. If a hook is not imported anywhere, delete it
  3. Document any hooks removed
- **Verify:** All remaining hooks are used somewhere
- **Done:** [ ]

### Task 2: Search for unused component imports
- **Type:** audit
- **Files:** `components/**/*.tsx`
- **Action:**
  1. Search for any components that are not imported by any page or other component
  2. Delete orphaned components
  3. Document any components removed
- **Verify:** All remaining components are used
- **Done:** [ ]

### Task 3: Clean up empty directories
- **Type:** cleanup
- **Files:** All directories
- **Action:** Remove any empty directories left after file deletions
- **Verify:** No empty directories remain
- **Done:** [ ]

## Verification
- [ ] No unused hooks exist
- [ ] No orphaned components exist
- [ ] No empty directories
- [ ] `npm run build` passes

## Success Criteria
- Codebase has no dead code
- Every file serves a purpose

## Output: SUMMARY.md
Document all files removed and any unexpected findings.
