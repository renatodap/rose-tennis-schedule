# Phase 09-01: Audit Hardcoded Strings and Colors

## Objective
Find all hardcoded UI values that should be extracted to constants.

## Context
@lib/constants.ts - already has BRAND_COLORS
@components/**/*.tsx
@app/**/*.tsx

## Tasks

### Task 1: Search for hardcoded colors
- **Type:** audit
- **Files:** All .tsx files
- **Action:**
  1. Search for hex color values (e.g., `#800000`, `#1f2937`)
  2. Search for Tailwind color classes that might need to use brand colors
  3. Search for `style={{ color:` or `style={{ backgroundColor:` with hardcoded values
  4. Document all findings
- **Verify:** Complete list of hardcoded colors
- **Done:** [ ]

### Task 2: Search for hardcoded strings
- **Type:** audit
- **Files:** All .tsx files
- **Action:**
  1. Search for app-specific strings (e.g., "Rose-Hulman", "RH Tennis")
  2. Search for repeated UI text that could be constants
  3. Search for URLs that are hardcoded
  4. Document all findings
- **Verify:** Complete list of hardcoded strings
- **Done:** [ ]

### Task 3: Identify common UI patterns
- **Type:** audit
- **Files:** All .tsx files
- **Action:**
  1. Look for repeated class strings (e.g., card styles)
  2. Look for repeated spacing/sizing patterns
  3. Document for potential extraction
- **Verify:** Common patterns documented
- **Done:** [ ]

## Verification
- [ ] Complete audit of hardcoded values
- [ ] Categorized list ready for extraction
- [ ] Priority order established

## Success Criteria
- Clear picture of what needs extraction
- Ready for systematic refactoring
